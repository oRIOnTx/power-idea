## Power IDEA 0.2.0

- Run and debug any language: detected run configurations, breakpoints and stepping for Ruby, Rust, Python and Go, and clickable `file:line` in every terminal
- Git like in JetBrains: Git Log with a commit graph, a Push dialog, a branch popup with ahead/behind, worktrees and a side-by-side conflict resolver
- New tool windows: Docker containers with live status, logs and shells; Database consoles with completion, editing and CSV export; Claude Session Insights
- Faster everyday editing: Replace in Files with a live preview, word completion everywhere, JetBrains-style Enter/Tab and multi-select Cut/Copy/Paste in the project tree
- Open single files from Finder or the command line in a lightweight editor, and extend the IDE with your own extensions
- The app shows its exact version on the Welcome screen — click it to copy for bug reports
