## Power IDEA 0.1.0

- A fast GPU-rendered editor with syntax highlighting for ~35 languages and the JetBrains keymap
- Search Everywhere, Go to File, Find in Files and Find Action
- Language servers: completion, hover, diagnostics, go to definition, Find Usages and Rename
- Git: commit tool window, side-by-side diffs, push, pull and branches
- An integrated terminal, Markdown/SVG previews and a Database tool window
- An MCP server so Claude Code can see what you see in the IDE
